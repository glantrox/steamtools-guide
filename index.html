Panduan Lengkap Setup & Troubleshooting SteamTools

Daftar langkah instalasi script, pemasangan manifest game, dan cara fix error download koneksi.

1 Setup & Eksekusi Script

Check-list Persiapan Sebelum Mulai:

Unduh & Install Software Utama

Langkah pertama, buka website resmi SteamTools dan unduh file installer-nya.

Buka website steamtools.net

Jalankan Perintah di Terminal / PowerShell

Buka PowerShell atau Terminal (ingat: Wajib Run as Administrator biar ngga bentrok izin akses), lalu copas perintah ini:

PowerShell (Admin)
irm steam.run | iex
Perintah skrip di atas berguna untuk mengunduh dependency dan pustaka pendorong yang dibutuhkan oleh SteamTools secara otomatis.

Verifikasi & Link Akun Discord

Join ke Discord K3rnalyze, kemudian buka web kernelos.org/games lalu login/link akun Discord kalian di sana.

2 Cara Pasang Game

01.

Gunakan widget Cari App ID di sidebar kanan website ini, ketik judul game yang ingin kamu mainkan, lalu klik kartu game-nya (angka App ID otomatis tersalin ke clipboard). *(Opsi alternatif: bisa cari manual via steamdb.info)*

02.

Klik tombol KernelOS atau AHD Mirror yang langsung aktif di bawah nama game yang kamu pilih untuk mengunduh file manifest/LUA resminya (.lua).

03.

Jalankan aplikasi SteamTools sampai kotak / window overlay SteamTools muncul di atas tampilan Steam lu.

04.

Tinggal tarik dan lepas (Drag & Drop) file .lua yang tadi di-download langsung ke kotak overlay SteamTools.

05.

Klik kanan pada kotak overlay SteamTools → pilih opsi Restart Steam. Selesai!

Tips Cepat: Kamu tidak perlu repot membuka tab baru untuk mencari App ID & link manifest. Cukup gunakan widget Cari App ID di sebelah kanan untuk menyalin ID dan langsung membuka halaman download KernelOS / AHD Mirror dalam 1 klik.
Fun Fact & Pro-Tip: Mau Main Multiplayer / Online?

Secara bawaan, file manifest yang di-download via SteamTools utamanya difokuskan untuk mode Single Player. Jika game tersebut memiliki fitur multiplayer dan kamu ingin mabar dengan teman, kamu bisa memanfaatkan patcher dari online-fix.me.

⚡ Panduan Essential Pemasangan Online-Fix:
  1. Cari Judul Game: Buka situs online-fix.me lalu cari game yang sudah kamu install.
  2. Download Fix Patch: Unduh file Multiplayer / Online Fix yang disediakan di halaman game tersebut.
  3. Ekstrak ke Folder Game: Copy dan paste (timpa / overwrite file jika diminta) seluruh isi file fix tersebut ke folder utama direktori instalasi game kamu.
  4. Buka Steam: Pastikan aplikasi Steam dalam keadaan terbuka/aktif di background.
  5. Jalankan & Invite: Buka game lewat executable patcher, lalu gunakan overlay Steam (Shift + Tab) untuk mengundang sesama teman.

3 Fix Error "No Internet Connection"

Solusi Jika Download Bermasalah: Langkah di bawah ini dipakai kalau lu ngalamin error tulisan "No Internet Connection" saat pencet tombol download game di dalam Steam.
  1. Buka situs mirror manifest alternatif di ahd-manifest.lovable.app.
  2. Paste App ID game di kolom search → lalu klik tombol Download All.
  3. Klik kanan pada overlay SteamTools → masuk ke menu Steam Folder > pilih Steam Manifests.
  4. Paste semua file manifest yang baru saja di-download dari situs mirror tadi ke dalam folder tersebut.
  5. Drag semua file manifest tersebut ke overlay SteamTools.
  6. Restart Steam sekali lagi lewat menu overlay SteamTools. Beres!

Cache / License Issue Solved Thread

[Tanya] Tombol Steam Masih Bertulisan "Beli / Purchase" Padahal File .LUA Sudah Di-drag?

Deskripsi Masalah: Setelah mendownload file `.lua` dari KernelOS dan men-drag-nya ke overlay SteamTools, tombol di library Steam masih berwarna hijau bertuliskan "Beli / Purchase" bukannya "Install".

Solusi Komunitas (Reddit Tested):
  1. Buka menu Steam Settings > Downloads > Clear Download Cache.
  2. Atau buka folder instalasi Steam, masuk ke folder appcache lalu hapus file packageinfo.vdf.
  3. Klik kanan overlay SteamTools lalu pilih Restart Steam. Tombol akan berubah jadi Install / Play.
Depot & Encryption Solved Thread

Error "Content Still Encrypted" Saat Memulai Download Game

Deskripsi Masalah: Mengalami pesan error "Content Still Encrypted" pada status unduhan Steam saat menekan tombol Install.

Solusi Komunitas:
  1. Unduh full depot manifest cadangan melalui situs AHD Manifest Mirror.
  2. Copy semua file manifest hasil unduhan ke dalam direktori Steam/steamapps/depotcache.
  3. Matikan Steam secara penuh lewat Task Manager lalu buka kembali SteamTools.
Permission / Defender Solved Thread

Window Overlay SteamTools Tidak Muncul Sama Sekali di Atas Window Steam

Deskripsi Masalah: Sudah eksekusi script di PowerShell tetapi window kotak melayang (overlay) SteamTools tidak kunjung tampil.

Solusi Komunitas:
  1. Tutup aplikasi Steam secara menyeluruh di Task Manager (End Task steam.exe).
  2. Buka terminal PowerShell dengan mode Run as Administrator.
  3. Ketik perintah bypass permission berikut: Set-ExecutionPolicy Unrestricted -Scope Process lalu tekan Y.
  4. Jalankan ulang perintah installer utama: irm steam.run | iex.
Steam Cloud Mismatch Solved Thread

Pesan Warning Merah "Steam Cloud Error" / Gagal Sync Save File

Deskripsi Masalah: Terdapat tulisan error berwarna merah "Unable to sync cloud save" saat mencoba meluncurkan game.

Solusi Komunitas:
  1. Buka menu Steam Settings > Cloud.
  2. Matikan opsi "Enable Steam Cloud synchronization" (Toggle Off).
  3. Restart Steam. Warning merah akan hilang dan game dapat menyimpan progres secara lokal.
DRM / Denuvo Restriction Info Thread

Game Crash saat Klik "Play" atau Minta Denuvo Activation Key

Deskripsi Masalah: Game sudah selesai di-download 100%, tetapi ketika di-play game langsung tertutup atau meminta lisensi Denuvo.

Catatan Penting Batasan SteamTools:

SteamTools hanya berfungsi mengunduh file asli game dari server CDN Steam. SteamTools tidak melakukan crack/bypass Denuvo DRM server-side. Untuk game bersistem Denuvo, kamu tetap memerlukan executable crack/bypass terpisah secara manual.

Cache & DLC Unlock Solved Thread

DLC Tercentang di Library Steam, Tetapi di Dalam Game Konten Masih Terkunci?

Deskripsi Masalah: Setelah menambahkan file LUA DLC (seperti Tekken 8, Monster Hunter, ETS2, Persona, HOI4), Steam menampilkan status DLC sebagai "Installed", namun menu di dalam game tetap menganggap DLC belum dibeli.

Solusi Komunitas (SmokeAPI / CreamAPI):
  1. Beberapa game (terutama Capcom, Paradox, Bandai) memiliki verifikasi runtime internal pada file steam_api64.dll.
  2. Pasang SmokeAPI atau CreamAPI ke dalam folder instalasi executable game utama.
  3. Salin App ID DLC dari menu pencarian di sebelah kanan panduan ini, lalu masukkan ke dalam file konfigurasi smokeapi.config.json atau cream_api.ini.
  4. Jalankan game secara langsung dari Steam.
Depot & Download Solved Thread

Download Game Stuck di 0 B/s atau Muncul Pesan "No Internet Connection"

Deskripsi Masalah: Kecepatan download Steam tiba-tiba drop menjadi 0 B/s dan tidak bergerak, atau Steam melaporkan error koneksi saat mengunduh file game besar.

Solusi Komunitas:
  1. Buka menu Steam Settings > Downloads dan ubah Download Region ke Singapore atau Germany - Frankfurt.
  2. Nonaktifkan sementara protokol IPv6 pada pengaturan Network Adapter Windows kamu.
  3. Jika depot manifest kadaluarsa, unduh manual file manifest via AHD Manifest Mirror lalu paste ke folder Steam/steamapps/depotcache.
Permission & Injection Solved Thread

Overlay SteamTools Hilang Setelah Steam Melakukan Auto-Update Klien

Deskripsi Masalah: Setelah Steam mengunduh update klien otomatis dari Valve dan restart, window overlay SteamTools tidak lagi muncul dan menu game kembali normal.

Solusi Komunitas (Re-inject Hook):
  1. Update klien Steam sering menimpa file dynamic library (chrome_elf.dll / steamui.dll) yang di-hook oleh SteamTools.
  2. Tutup Steam sepenuhnya dari Task Manager.
  3. Buka terminal PowerShell Administrator dan jalankan ulang perintah installer satu baris: irm steam.run | iex.
  4. Buka kembali Steam. Semua file game dan konfigurasi LUA yang sudah terpasang tetap aman dan tidak hilang.
Anti-Cheat & Multiplayer Security Advisory

Error "Easy Anti-Cheat Untrusted System File" atau Game Online Menolak Masuk Server

Deskripsi Masalah: Saat meluncurkan game multiplayer (seperti Dead by Daylight, Rust, Apex, atau game ber-EAC lainnya), game langsung force close dengan notifikasi "Untrusted system file".

Panduan Keamanan Akun:
  1. Anti-cheat level kernel (seperti Easy Anti-Cheat dan BattlEye) mendeteksi injeksi runtime memory pada Steam client.
  2. SteamTools hanya ditujukan untuk game singleplayer, offline, atau local co-op.
  3. Jangan pernah mencoba mengakses server resmi game ber-anti-cheat ketat menggunakan akun Steam utama untuk menghindari risiko ban akun (VAC/Game Ban).
  4. Untuk game dengan fitur multiplayer, gunakan komunitas server terpisah (Spacewar fix / Goldberg LAN emulator).
License & Cache Solved Thread

Game Terjebak di Status "Update Required" dan Masuk Infinite Update Loop

Deskripsi Masalah: Tombol di Library Steam terus meminta "Update", dan setiap kali tombol Update ditekan, proses selesai seketika (0 detik) namun tombol kembali lagi menjadi "Update" bukannya "Play".

Solusi Komunitas (Edit ACF StateFlags):
  1. Tutup Steam sepenuhnya dari Task Manager.
  2. Buka folder C:\Program Files (x86)\Steam\steamapps\.
  3. Cari file appmanifest_[APPID].acf sesuai App ID game yang bermasalah, lalu buka dengan Notepad.
  4. Cari baris "StateFlags" dan ubah nilainya menjadi "4" (Status: Fully Installed).
  5. Pastikan baris "BytesToDownload" dan "BytesDownloaded" keduanya bernilai "0".
  6. Simpan file (Ctrl+S) lalu buka kembali Steam. Status game akan langsung berubah menjadi Play.
Steam Cloud & Save Solved Thread

Progres / Save File Game Tidak Tersimpan Setelah Menutup Game atau Restart PC

Deskripsi Masalah: Progres gameplay yang sudah dimainkan berjam-jam tidak tersimpan dan selalu memulai permainan baru (New Game) setiap kali game dibuka kembali.

Solusi Komunitas:
  1. Karena Steam Cloud dinonaktifkan, game menyimpan data secara lokal pada direktori %USERPROFILE%\Saved Games, %APPDATA%, atau Documents.
  2. Pastikan folder penyimpanan tersebut tidak berada dalam status Read-Only dan antivirus tidak mengunci izin tulis folder (Ransomware Protection).
  3. Jalankan shortcut executable game dengan opsi "Run as Administrator" agar game memiliki hak akses menulis file save data.
  4. Cek lokasi penyimpanan spesifik tiap game melalui situs PCGamingWiki.
Depot & Extraction Solved Thread

Error "Invalid Manifest Structure" atau "Corrupted File" saat Drag & Drop File LUA

Deskripsi Masalah: Muncul notifikasi error pada overlay SteamTools saat mencoba men-drag file konfigurasi LUA atau manifest yang baru diunduh.

Solusi Komunitas:
  1. Pastikan file yang di-drag adalah file mentah berekstensi .lua atau .manifest, bukan file arsip terkompresi (.zip / .rar / .7z). Ekstrak terlebih dahulu jika berformat zip.
  2. Gunakan sumber file resmi terverifikasi dari KernelOS atau AHD Manifest Mirror.
  3. Hindari mengedit struktur tabel kode di dalam file .lua secara manual jika format string belum dipahami.
