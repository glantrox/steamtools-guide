1 Setup & Eksekusi Script

Check-list Persiapan Sebelum Mulai:

Unduh & Install Software Utama

Langkah pertama, buka website resmi SteamTools dan unduh file installer-nya.

Buka website steamtools.net

Jalankan Perintah di Terminal / PowerShell

Buka PowerShell atau Terminal (ingat: Wajib Run as Administrator biar ngga bentrok izin akses), lalu copas perintah ini:

PowerShell (Admin)
irm steam.run | iex
Perintah skrip di atas berguna untuk mengunduh dependency dan pustaka pendorong yang dibutuhkan oleh SteamTools secara otomatis.

Verifikasi & Link Akun Discord

Join ke Discord K3rnalyze, kemudian buka web kernelos.org/games lalu login/link akun Discord kalian di sana.

2 Cara Pasang Game

01.

Buka situs steamdb.info, cari game yang ingin lu mainin, lalu copy angka App ID game-nya.

02.

Paste App ID tadi di kernelos.org/games lalu download file manifest-nya yang berformat .lua.

03.

Jalankan aplikasi SteamTools sampai kotak / window overlay SteamTools muncul di atas tampilan Steam lu.

04.

Tinggal tarik dan lepas (Drag & Drop) file .lua yang tadi di-download langsung ke kotak overlay SteamTools.

05.

Klik kanan pada kotak overlay SteamTools → pilih opsi Restart Steam. Selesai!

Fun Fact & Pro-Tip: Mau Main Multiplayer / Online?

Secara bawaan, file manifest yang di-download via SteamTools utamanya difokuskan untuk mode Single Player. Jika game tersebut memiliki fitur multiplayer dan kamu ingin mabar dengan teman, kamu bisa memanfaatkan patcher dari online-fix.me.

⚡ Panduan Essential Pemasangan Online-Fix:
  1. Cari Judul Game: Buka situs online-fix.me lalu cari game yang sudah kamu install.
  2. Download Fix Patch: Unduh file Multiplayer / Online Fix yang disediakan di halaman game tersebut.
  3. Ekstrak ke Folder Game: Copy dan paste (timpa / overwrite file jika diminta) seluruh isi file fix tersebut ke folder utama direktori instalasi game kamu.
  4. Buka Steam: Pastikan aplikasi Steam dalam keadaan terbuka/aktif di background.
  5. Jalankan & Invite: Buka game lewat executable patcher, lalu gunakan overlay Steam (Shift + Tab) untuk mengundang sesama teman.

3 Fix Error "No Internet Connection"

Solusi Jika Download Bermasalah: Langkah di bawah ini dipakai kalau lu ngalamin error tulisan "No Internet Connection" saat pencet tombol download game di dalam Steam.
  1. Buka situs mirror manifest alternatif di ahd-manifest.lovable.app.
  2. Paste App ID game di kolom search → lalu klik tombol Download All.
  3. Klik kanan pada overlay SteamTools → masuk ke menu Steam Folder > pilih Steam Manifests.
  4. Paste semua file manifest yang baru saja di-download dari situs mirror tadi ke dalam folder tersebut.
  5. Restart Steam sekali lagi lewat menu overlay SteamTools. Beres!

Cache / License Issue Solved Thread

[Tanya] Tombol Steam Masih Bertulisan "Beli / Purchase" Padahal File .LUA Sudah Di-drag?

Deskripsi Masalah: Setelah mendownload file `.lua` dari KernelOS dan men-drag-nya ke overlay SteamTools, tombol di library Steam masih berwarna hijau bertuliskan "Beli / Purchase" bukannya "Install".

Solusi Komunitas (Reddit Tested):
  1. Buka menu Steam Settings > Downloads > Clear Download Cache.
  2. Atau buka folder instalasi Steam, masuk ke folder appcache lalu hapus file packageinfo.vdf.
  3. Klik kanan overlay SteamTools lalu pilih Restart Steam. Tombol akan berubah jadi Install / Play.
Depot & Encryption Solved Thread

Error "Content Still Encrypted" Saat Memulai Download Game

Deskripsi Masalah: Mengalami pesan error "Content Still Encrypted" pada status unduhan Steam saat menekan tombol Install.

Solusi Komunitas:
  1. Unduh full depot manifest cadangan melalui situs AHD Manifest Mirror.
  2. Copy semua file manifest hasil unduhan ke dalam direktori Steam/steamapps/depotcache.
  3. Matikan Steam secara penuh lewat Task Manager lalu buka kembali SteamTools.
Permission / Defender Solved Thread

Window Overlay SteamTools Tidak Muncul Sama Sekali di Atas Window Steam

Deskripsi Masalah: Sudah eksekusi script di PowerShell tetapi window kotak melayang (overlay) SteamTools tidak kunjung tampil.

Solusi Komunitas:
  1. Tutup aplikasi Steam secara menyeluruh di Task Manager (End Task steam.exe).
  2. Buka terminal PowerShell dengan mode Run as Administrator.
  3. Ketik perintah bypass permission berikut: Set-ExecutionPolicy Unrestricted -Scope Process lalu tekan Y.
  4. Jalankan ulang perintah installer utama: irm steam.run | iex.
Steam Cloud Mismatch Solved Thread

Pesan Warning Merah "Steam Cloud Error" / Gagal Sync Save File

Deskripsi Masalah: Terdapat tulisan error berwarna merah "Unable to sync cloud save" saat mencoba meluncurkan game.

Solusi Komunitas:
  1. Buka menu Steam Settings > Cloud.
  2. Matikan opsi "Enable Steam Cloud synchronization" (Toggle Off).
  3. Restart Steam. Warning merah akan hilang dan game dapat menyimpan progres secara lokal.
DRM / Denuvo Restriction Info Thread

Game Crash saat Klik "Play" atau Minta Denuvo Activation Key

Deskripsi Masalah: Game sudah selesai di-download 100%, tetapi ketika di-play game langsung tertutup atau meminta lisensi Denuvo.

Catatan Penting Batasan SteamTools:

SteamTools hanya berfungsi mengunduh file asli game dari server CDN Steam. SteamTools tidak melakukan crack/bypass Denuvo DRM server-side. Untuk game bersistem Denuvo, kamu tetap memerlukan executable crack/bypass terpisah secara manual.
