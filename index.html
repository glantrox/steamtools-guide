1 Setup & Eksekusi Script

Check-list Persiapan Sebelum Mulai:

Unduh & Install Software Utama

Langkah pertama, buka website resmi SteamTools dan unduh file installer-nya.

Buka website steamtools.net

Jalankan Perintah di Terminal / PowerShell

Buka PowerShell atau Terminal (ingat: Wajib Run as Administrator biar ngga bentrok izin akses), lalu copas perintah ini:

PowerShell (Admin) _
irm steam.run | iex

Perintah skrip di atas berguna untuk mengunduh dependency dan pustaka pendorong yang dibutuhkan oleh SteamTools secara otomatis.

Verifikasi & Link Akun Discord

Join ke Discord K3rnalyze, kemudian buka web kernelos.org/games lalu login/link akun Discord kalian di sana.

2 Cara Pasang Game

  1. Gunakan widget Cari App ID di sidebar kanan website ini, ketik judul game, lalu klik kartu game-nya.
  2. Klik tombol KernelOS atau AHD Mirror untuk mengunduh file manifest/LUA resminya (.lua).
  3. Jalankan aplikasi SteamTools sampai window overlay muncul di atas Steam.
  4. Drag & Drop file .lua langsung ke kotak overlay SteamTools.
  5. Klik kanan overlay SteamTools -> pilih Restart Steam. Selesai!
Fun Fact & Pro-Tip: Mau Main Multiplayer / Online?

Secara bawaan, manifest SteamTools terutama difokuskan untuk Single Player. Untuk mabar multiplayer dengan teman, unduh fix patch tambahan dari online-fix.me lalu timpa ke folder game.

3 Fix Error "No Internet Connection"

Solusi Jika Download Bermasalah: Langkah di bawah ini dipakai kalau lu ngalamin error tulisan "No Internet Connection" saat pencet tombol download game di dalam Steam.

  1. Buka situs mirror manifest alternatif di ahd-manifest.lovable.app.
  2. Paste App ID game di kolom search -> lalu klik Download All.
  3. Klik kanan overlay SteamTools -> Steam Folder > Steam Manifests.
  4. Paste semua file manifest yang baru saja di-download ke folder tersebut.
  5. Drag semua file manifest tersebut ke overlay SteamTools.
  6. Restart Steam sekali lagi lewat menu overlay SteamTools. Beres!
